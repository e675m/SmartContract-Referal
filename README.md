# Referral Smart Contract DApp (Diploma Project)

## 📌 Описание проекта

Данное веб-приложение реализует простую реферальную систему на базе смарт-контракта с возможностью регистрации пользователей, указания реферера, начисления бонусов и получения данных о пользователях. Проект создан в рамках дипломной работы и **не предназначен для деплоя в основную сеть**.

Также используется **оракул Chainlink** для получения внешних данных (например, цены ETH).

---

## 🧱 Стек технологий

- **Solidity** – для написания смарт-контракта
- **Remix IDE** – для тестирования и деплоя контракта
- **Ethers.js** – взаимодействие фронтенда с контрактом
- **HTML + JavaScript** – интерфейс пользователя
- **MetaMask** – для подключения кошелька

---

## ⚙️ Функциональность

### ✅ Основной функционал:

- Регистрация пользователя с указанием реферера
- Защита от повторной регистрации
- Начисление бонусов рефереру
- Просмотр всех зарегистрированных пользователей
- Просмотр бонусов
- Получение внешней информации через оракул (например, курс ETH)

---

## 🚀 Запуск проекта

1. Установите MetaMask и переключитесь на Remix VM или локальную сеть.
2. Задеплойте контракт в Remix.
3. Скопируйте адрес контракта и вставьте его в `app.js`.
4. Откройте `index.html` в браузере.
5. Подключите MetaMask и начните тестирование.
