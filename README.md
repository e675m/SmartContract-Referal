# 📢 Referral DApp

Децентрализованное приложение (DApp) на основе смарт-контракта ERC-20 с поддержкой реферальной системы и интеграцией Chainlink Oracle.

---

## ⚙️ Технологии

- **Solidity** (>=0.8.0)
- **OpenZeppelin** (ERC20, Ownable)
- **Chainlink Price Feed** (ETH/USD)
- **ethers.js**
- **HTML + Bootstrap 5**
- **MetaMask**

---

## 📜 Основной функционал

### 🔹 Контракт `ReferralProgram.sol`

#### 👤 Регистрация

- `register(address referrer)` — регистрация по реферальной ссылке
- `registerSolo()` — самостоятельная регистрация

#### 🎁 Бонусы

- При регистрации через реферала:
  - 70% токенов — рефереру
  - 30% токенов — приглашённому
- При самостоятельной регистрации бонус не начисляется

#### 🧩 Другие функции

- `getReferrers()` — получить список ваших рефералов
- `getMyBonus()` — текущий бонус пользователя
- `getLastPrice()` — курс ETH/USD через Chainlink
- `getBonus(address)` — бонус конкретного адреса (для админа)
- `getRef(address)` — чей это реферал (для админа)
