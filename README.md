# Referral DApp

Децентрализованное приложение (DApp) на основе смарт-контракта ERC-20 с поддержкой реферальной системы и интеграцией Chainlink Oracle.

---

## Технологии

- **Solidity** (>=0.8.0)
- **OpenZeppelin** (ERC20, Ownable)
- **Chainlink Price Feed** (ETH/USD)
- **Nodejs** (oracle)
- **ethers.js**
- **HTML + Bootstrap 5**
- **JavaScript**
- **MetaMask**

---

##  Основной функционал

###  Контракт `ReferralProgram.sol`

#### Регистрация

- `registerSolo()` — регистрация

#### Бонусы

Бонус начисляется при выполнении действий рефералом на сайте клиента

## Интерфейс пользователя

### Основные разделы

- **Регистрация**
- **Моя реферальная ссылка**
- **Информация**
- **Курс ETH и расчет бонуса**
- **Админ панель**

---

## Безопасность

-  Chainlink Oracle безопасно подключен
-  Админ-функции только для владельца
-  Защита от спама и не ораганизованных запросов в виде капчи

---

## Тестирование

-  Проверка регистрации
-  Проверка коректности реферальной ссылки
-  Проверка отображения списка рефералов
-  Проверка отображения бонусов
-  Проверка курса ETH через Chainlink
-  Админ-функции: Смена адреса оракула
